# FireMan — SVG Studio Android

Offline Kotlin Android vector editor source project.

The project source is organized under `SVGStudio-Android/`. It includes native SVG shape tools, gradients, layer controls, editable SVG/XML source, clipboard copy, SVG import/export, and a Termux release build script.

See `SVGStudio-Android/README.md` for build instructions. Requires JDK 17, Gradle 8.9+, Android SDK Platform 35 and Build Tools 35.0.0.
